# statusbar：输入框外壳与后台任务

没有独立底栏：底栏工厂只拿主题、扩展状态与 Git 分支并装上复制清理，自己画 0 行；状态画进编辑器的上下边框（`index.ts` 的 `ShellEditor`）。上边框左边是回合火苗、“处理中”或“等待 N 个子代理”与计时、主会话审查进度，歇下后定格为轮记录（`✓ 耗时 · 均速`）（耗时是从你发话到它停下的墙钟时间，均速是模型出字速度；中断或失败时先写“已中断”“请求失败”），右边留空。下边框左边是工作目录（`~` 写法，窄了按整段省略，`render.ts` 的 `pathTail`），右边是模型/思考档、Fast、上下文百分比与容量。退让顺序写在 `render.ts` 的 `topBorder`/`bottomBorder`，横线与光晕由 `../master/border.ts` 统一绘制（子代理视图输入区同一份），颜色全部取自当前主题。宿主自带的 Working 行由火苗取代，在这里关掉。不显示订阅额度。

后台任务：扩展在 `agents/jobs.ts` 的任务登记簿（`globalThis[Symbol.for("butler.jobs")]`）里登记正在跑的事（哨兵、调研、审查、worker、会话哨兵的待办）。输入框上方的一块（`JobsRows`，`render.ts` 的 `jobRows`）只管还在跑的：收起时一行，`▸`、火苗或 `!`、数量（`哨兵 2 · 调研 1（4 人）`，没有归类的算 `其他 N`）、`等你 N`，再顺带最急的一件（在等你的优先）；点这一行展开，每个任务一行：角色、裁到 24 列的标题（`TITLE_COLUMNS`，全文在弹窗里）、此刻在做什么、已用时间，不限行数；再点第一行收起，点任务行打开它的弹窗。worker 不进这一块（指挥官的活动列表已逐个列出子代理），只在弹窗里。任务可以标 `quiet`：内置的会话哨兵平时没事可说，算进数量但不占行；全是安静任务时整块隐藏。任务结束那一行就消失；登记簿留着结局，弹窗里看。

任务可以带 `items`（要用户处理的事项）和 `act`：弹窗右边会列出“要你处理的事（N）”，一条一行带编号、标签和时间；数字键或点击选中一条，下面出现按钮，每个按钮上写着快捷键（按字母或点按钮都走任务的 `act`，回车 = 第一个按钮；动作带 `close` 时弹窗随之关掉），处理完选中下一条。事项多了：`group` 把它们分组（标题行 `── 建议去做（N）`），`hint` 是写在条目后面的建议理由；空格给选中的一条打勾（行首 `□`/`■`，点它也行），`a` 勾上整组；有勾选时按钮的字母对整批生效（任务的 `actMany`）；`tools` 是对整个任务的按钮（整理、照建议处理、暂停接力），点或按字母调用 `act("", key)`。会话哨兵靠它让用户直接“去做”或“忽略”，不用敲命令。

后台任务弹窗（`jobs-popup.ts`）：点输入框上方的某一行任务、按 `Ctrl+\`（或终端把 Option 当 Alt 的话 `Alt+J`；macOS 默认 Option+J 发出来的是字符 `∆`，不行）打开，没有任何任务时也能开（显示“现在没有后台任务”），布局像 Telescope——宽屏（≥84 列）左边是任务列表（上下键、ctrl-n/p、j/k 或点击选择），右边是选中那项的详情：状态（已派出，进行中 / 在等你 / 已完成 / 失败 / 已停止）、任务全文、模型、进度（含并发成员各自的状态和模型）、开始和结束时间与用时，之后是结果、最近动态、过程记录位置；窄屏退回“列表 → 回车看详情”。已结束的任务变灰，排在最下面（登记簿留最近 20 个），`c` 清掉。可选中的东西都有明显的样子：选中的行有底色，按钮（返回、关闭、看完整过程）有底色，成员前面是 `▸`——tmux 里 Pi 只上报点击和拖动、不上报鼠标悬停，所以没有悬停高亮。再往里：选中任务按回车（或 →，或直接点成员）进入成员（调研员、审查者），再回车看这一位的完整过程——调用了什么工具、传了什么、返回什么、模型说了什么，带时间、实时，模型说的话和想的按 Markdown 渲染，工具调用的参数一项一行，返回的内容保留行结构（只显示前 12 行），`↑↓`/PgUp/PgDn/滚轮滚动、`G` 回到最新；worker 没有成员，回车直接看它自己的过程；哨兵看每次检查的记录。弹窗总高不超过终端的 80%（`HEIGHT_RATIO`），放不下的右边详情、左边列表、过程页都可以滚动，提示行和底边框永远看得见。复制：`../session/clean-copy.ts` 接管 Pi 全屏模式取选中文字的那一步（底栏工厂挂载时装上），去掉用户消息左边的 `▎` 竖条，并把写满屏宽的自动折行接回去，长路径、网址复制出来是完整的一条；`tests/clean-copy.test.ts`（逻辑）和 `tests/copy.e2e.mjs`（真实终端拖选、读剪贴板，会备份并恢复文本剪贴板）。

弹窗底边框嵌着会话统计：缓存命中、会话平均 In/Out/Total 速度、Git 分支、会话 ID 开头 8 位（`--session` 按开头匹配），窄屏先丢速度，再丢分支与缓存。`metrics.ts` 从当前分支计算 Cache Hit = cacheRead / (cacheRead + cacheWrite)；速度为非缓存 input/output token 除以合并后的 user→assistant 时间区间，排除用户空闲间隔，恢复会话可重建；只在分支末端变了时重新扫描。

`popupLines()` 是不碰终端的纯函数，单元测试和 tmux 端到端（`agents/e2e/footer-jobs.e2e.mjs`、`footer-workers.e2e.mjs`、`loose-footer.e2e.mjs`，发真实鼠标序列）都覆盖。

链接保护：`../session/link-space.ts` 在 Pi 渲染 Markdown 之前（`registerMarkdownTransformer`），给“网址或绝对路径”和紧跟着的全角标点之间补一个空格，免得终端把“。报告里…”也算进链接、点开是错的（代码块、行内代码、网址里自带汉字的不动）。配置里 `features.links` 关掉；`tests/link-space.test.ts`（逻辑）和 `tests/link-space.e2e.mjs`（真实终端，带关掉功能的对照组）。写法本身的规矩在 `skill-integration.md` 的“Links and paths in text”。
